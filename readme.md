# Интерактивная карта КРТ Москвы и деловых локаций

🗺 **[Открыть карту](https://arkadiyshid.github.io/project_4/)**

## О проекте

Интерактивная карта проектов комплексного развития территорий (КРТ) Москвы.
Карта показывает:

- статус проектов (в реализации / планируемые / иной статус);
- жилой и нежилой ТЭП (технико-экономические показатели);
- функциональное назначение проектов;
- агрегацию ТЭП по районам, в том числе в пересчёте на жителя;
- связь проектов КРТ с деловыми локациями.

Карта построена на Python (GeoPandas + Folium) и опубликована через GitHub Pages.

## Возможности карты

- Картограммы жилого и нежилого ТЭП по районам
- Полигоны КРТ по статусу и функциональному типу
- Деловые локации и КРТ, попадающие в них
- Картодиаграммы и тепловые карты
- Кластеры маркеров, поиск по районам и проектам
- Полноэкранный режим, мини-карта, измерение расстояний, координаты курсора

## Методика

1. **Очистка:** исправление геометрий, нормализация названий районов
   (регистр, ё→е, пробелы), приведение ТЭП из строк к числам,
   удаление подтверждённых дубликатов (совпадают название, геометрия и все ТЭП).
2. **ТЭП:** нежилой ТЭП = нежилое назначение + общественно-деловая застройка.
3. **Классификация проектов:**
   - жилой ТЭП > 0 → «Жилое КРТ»;
   - иначе нежилой ТЭП > 0 → «Нежилое КРТ»;
   - иначе → «Назначение не определено».
4. **Пространственная привязка:** по центроиду полигона КРТ (EPSG:32637).
   Весь ТЭП проекта относится к району и к деловым локациям,
   в которые попал центроид.
5. **Агрегация:** суммы ТЭП по районам и деловым локациям, ТЭП на жителя.
6. **Контроль качества:** таблицы проблемных записей (дубликаты, нулевой ТЭП,
   центроид вне полигона, несовпадение районов и др.).

## Ограничения

1. Весь ТЭП проекта относится к одному району по центроиду,
   без распределения по площади пересечения.
2. Связь с деловой локацией определяется только попаданием центроида в полигон.
3. Центроид мультиполигона может оказаться вне территории проекта.
4. Тепловые карты строятся по центроидам, а не по площади проектов.
5. Категория «Жилое КРТ» присваивается при любом жилом ТЭП > 0,
   даже если преобладает нежилая застройка.
6. Коды поля `main` у деловых локаций не расшифрованы.
7. Исходные данные содержат дубликаты, пропуски и опечатки в названиях полей.
8. Ключ картографической подложки виден в открытом виде в `index.html`.
9. Геометрия на веб-карте может быть упрощена для уменьшения размера файла;
   расчёты выполнены по исходной геометрии.

## Как запустить локально

```bash
git clone https://github.com/ЛОГИН/moscow-krt-map.git
cd moscow-krt-map
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
jupyter notebook main_pr_4.ipynb
```

Выполните все ячейки (**Kernel → Restart & Run All**).
Карта сохранится в `docs/index.html`.
